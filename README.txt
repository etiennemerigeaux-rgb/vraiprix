VraiPrix V0.3 — INSTALLATION\n1. Créer un dépôt GitHub public, puis déposer index.html, manifest.webmanifest et sw.js à la racine.\n2. Settings > Pages > Deploy from a branch > main > /(root) > Save.\n3. Ouvrir l’adresse HTTPS GitHub Pages dans Chrome. Autoriser la caméra.\n4. Tester le scanner. Si impossible, utiliser le bouton photo ou la saisie manuelle.\nIMPORTANT : ne pas ouvrir index.html directement depuis le ZIP pour tester la caméra.\nLes relevés restent dans localStorage par origine : sauvegarder le JSON dans V0.2 avant migration ; importer le JSON dans V0.3.\nLe scanner utilise ZXing chargé depuis un CDN (connexion Internet nécessaire au premier lancement).\n
